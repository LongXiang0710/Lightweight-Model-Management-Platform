# 动力站轻量化模型管理平台

基于 CesiumJS 的局域网三维模型审阅平台，直接读取项目提供的 `tileset.json` 与 `b3dm` 瓦片，不转换、不复制原始模型数据。

## 启动

```powershell
node server.mjs
```

启动命令会同时拉起两个独立进程：

- 前端网页服务：`0.0.0.0:5173`
- 后端模型与接口服务：`0.0.0.0:4173`

启动后终端会显示本机地址和局域网 IPv4 地址。同一局域网内的设备访问 `http://主机IPv4:5173` 即可，主机防火墙需允许 TCP 5173 与 4173 端口。

项目已本地化 Cesium 官方浏览器运行文件，无需联网安装依赖，也无需执行前端打包。可用 `node --check server.mjs` 等命令做 JavaScript 语法检查。

也可以分别启动前后端服务：

```powershell
node backend.mjs
node frontend.mjs
```

## 功能

- 直接加载 3D Tiles（`tileset.json` + 多精度 `b3dm`）
- 模型旋转、平移、缩放、复位、聚焦与全屏审阅
- 构件拾取、高亮及批次属性查看
- `structure.json` 模型结构按需加载，避免阻塞首屏
- 连续 LOD 替换、动态屏幕空间误差、缓存和局域网静态资源长缓存
- 页面内显示首屏加载耗时与实时 FPS

## 性能验收建议

使用部署主机或同一千兆局域网内的 Chrome / Edge 测试。首次打开观察页面左下角首屏耗时；操作模型时观察 FPS。实际指标受客户端显卡、浏览器及无线网络质量影响。

## 本机验收记录（2026-11-10）

- Microsoft Edge 首屏模型显示：`2.0s`
- 审阅交互帧率：`59–60 FPS`
- 已验证：按钮缩放、左键拖拽旋转、中键拖拽平移、自动旋转、复位、结构树按需加载
- 资源请求失败：`0`
- 浏览器控制台错误：`0`

原始 `tileset.json` 中 `gltfUpAxis` 的小写值已规范为标准大写 `Z`，否则 Cesium 会按默认轴向旋转 b3dm 几何，导致包围盒可见而模型不在视锥内。
